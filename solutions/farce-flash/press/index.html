Boilerplate, 50 words

Farce Systems builds reference kits for memory-constrained machine learning. Its design, the F.A.R.C.E. Flash — Flash Array for Resource-Constrained Environments — attaches to a Linux computer the owner already has and presents 1.28 TB of system-addressable memory from a 40-lane array of consumer MicroSD cards. That is ten times the capacity of an NVIDIA DGX Spark, which is a complete machine; the kit is a peripheral and the host is not included in its price.

Boilerplate, 100 words

Farce Systems builds open reference kits for memory-constrained machine learning. Its first design, the F.A.R.C.E. Flash — Flash Array for Resource-Constrained Environments — attaches to a computer the owner already has and presents 1.28 TB of system-addressable memory from a 40-lane array — ten times the capacity of an NVIDIA DGX Spark, which is a complete machine where this is a peripheral.

That capacity comes from forty consumer MicroSD cards. Farce Systems ships reference kits, not products: every component is an off-the-shelf part with a public datasheet, and the PCB design, assembly guide, and OpenFARCE software are open source. Before designing the array, Farce Systems commissioned an independent feasibility analysis of a 128 GB configuration and published it unedited, conclusion included.

(100 words)
